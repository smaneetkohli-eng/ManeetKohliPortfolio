# Portfolio bug audit — September 9, 2026

Baseline: `326e2bf` on `main`. The public HTML, CSS v44, and JS v20 were byte-for-byte identical to the checkout. No pre-existing local changes.

## Reproduced defects

- Desktop scrolling stalls on Hello there: the decorative shade expands `scrollHeight`, but its container has `overflow: visible`. The pager treats it as a native scroller forever.
- Scrolling over the dock can stall when an unrelated text container has remaining scroll range.
- Hidden pages, dock panels, project card backs, About articles, and hidden navigation prompts remain in the accessibility/focus tree.
- Space on a button is intercepted as a page-forward command.
- Ctrl-wheel zoom and mostly horizontal trackpad gestures are intercepted by the pager.
- Hash changes after initial load do not update the pager.
- Keyboard page commands skip overflowing text.
- Resize resets reading position; About steps inherit the prior step's scroll position.
- A shader module download/import failure prevents the whole script from running, disabling the pager and the documented visual fallback.

## Repair and verification scope

Keep vanilla HTML/CSS/JS, copy, desktop visual direction, page order, and z-index maps. Fix the gesture ownership and focus rules, decouple optional shaders from navigation, preserve reading state, and use transform-based transitions on narrow/coarse-pointer devices. Respect Reduced Motion. Bump both asset versions.

Use `python3 tests/serve.py`, then open `http://127.0.0.1:8081/tests/browser.html`. The browser harness exercises the real DOM/CSS/script and includes a simulated shader CDN outage. Verify live wheel navigation plus phone, tablet, and short landscape layouts. Physical-device Safari/Android acceptance remains separate from desktop browser viewport testing.

## Additional verified repairs

- A touch that began with horizontal jitter could be misclassified and skip unread copy.
- The 320px dock overlapped its signature, About/Projects buttons, and Contact CTA.
- Rapid project cycling cancelled an outgoing background's stop timer, leaving multiple engines running.
- Galaxy/edge shaders finishing asynchronously after departure (or after an edge host becomes hidden) ran offscreen.
- Enabling Reduce Motion prevented the reading-light loop's cleanup; preference changes now reconcile engines, and hidden tabs pause them.
- Reduced Motion page navigation retained invisible animation locks, while later CSS overrode the Projects motion preference. Animation locks are removed under reduced motion, but wheel momentum still gets its own cooldown.

Node lifecycle regressions run with `node --test tests/engine-lifecycle.mjs`. The browser fixture simulates failed shader imports and Reduced Motion locally; the production code contains no test switches. Test harnesses and this report are excluded from Vercel uploads through `.vercelignore`.

- Wide, short windows clipped Bio, About, and Contact content without a scrollbar. Their desktop layouts now retain their columns while exposing a scroll range below the dock.
